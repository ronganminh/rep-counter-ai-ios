Consent + privacy rules
  • Three scopes, each asked in context; declining one never blocks workouts or other scopes
  • Before any send: check scope + consentVersion. On revoke: cancel in-flight, delete outbox for that scope, send one deletion request (proposed)
  • Never sent: video, images, face, keypoints, device id, name. Only aggregated metrics (v1 rule extended)
  • Copy states that a backend and third-party model provider are involved and that AI can be wrong
  • Re-prompt at most once per 14 days after "Not now" (proposed)
Safety + trust
  • General fitness guidance only. No diagnosis, injury or medical claims; v1 disclaimer kept on every AI surface
  • Recommendations limited to the user's level and plan bounds; never shorten rest or add sets beyond plan
  • Hedged language required when confidence is limited; no form comments for manual or timer data
  • Server-side output checks (format, banned claims) before display; failures → P4-10g
Free / Pro (proposed)
  • Free: camera workouts, counting, plans, progress, after-workout feedback, on-device quick tips
  • Allowance-based: coach chat, progress reviews, goal suggestions
  • Pro (Phase 8): larger allowance. No prices, quotas or reset dates defined here; all sample numbers marked SAMPLE
  • No paywall during workouts or on Results
Localization + accessibility
  • English-first; vi-VN strings from v1 for feedback card. AI responses requested in the user locale
  • Fixed UI strings (prompts, errors, consent) in string tables; AI text never used for buttons
  • Chat input supports IME; bubbles grow, never truncate. Allow 35% expansion in chips (wrap)
  • Screen readers: AI chip read as "AI interpretation"; Recorded as "Recorded data". Loading bubble is a live region. Thumbs and toggles 48 pt
Existing vs proposed
  • Existing (v1): per-workout AI feedback card, consent sheet, single AI toggle, offline rule feedback, aggregated payload, no video upload
  • Proposed (Phase 4): coach overview, full feedback view, reviews, recommendations, goals, chat, insight detail, scoped consent, usage, error matrix
  • Not claimed: live camera access by AI, real endpoints, real quotas, provider name
