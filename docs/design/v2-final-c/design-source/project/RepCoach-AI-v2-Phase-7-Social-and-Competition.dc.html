Server rules
  • Contributions processed idempotently by sessionSetId; edits after finalisation don't change results
  • Server-authoritative totals; client shows "confirmed" and "on this phone" separately
  • Winner: first to target by recordedAt (server-validated); else higher total; equal = tie
  • Eligibility: metric source must match; manual never counts for camera/timer metrics; daily cap 150 reps (proposed)
  • XP: completion grant once per competition via the Phase 5 ledger; no XP for rank or winning
  • Privacy enforced in every query (profile, search, leaderboard, invites); blocked pairs return not-found
  • Pagination: friends and leaderboard rows cursor-based (50)
  • Account deletion: remove profile, requests, friendships, snapshots rows (anonymised), shares; reports retained per policy
Offline + failure
  • Cached: friends list, last snapshot, own competition totals
  • Queued offline: nothing social (requests/invites/blocks need the server); workouts still record and sync later
  • Conflicts (409) return current state; UI shows "Already handled"
  • Leaderboard never re-ranked locally
Free / Pro (proposed)
  • Free: friends, requests, profiles, leaderboards, friend challenges, sharing, all privacy, blocking, reporting
  • Pro may add more simultaneous friend challenges or custom challenge types (Phase 8). No prices or quotas defined here
Accessibility + localization
  • Ranks as text ("=2", "1st"), status chips with text, never colour alone
  • Screen reader: "Sam, 52 of 100 push-ups, camera-counted"
  • Celebration icons static under Reduce Motion; no autoplay audio
  • Names up to 24 chars ellipsize; usernames never truncated in search results
  • All copy in string tables; dates/numbers per locale
