Proposed analytics contracts
WorkoutSummary { sessionId, date, name, scheduledWorkoutId?,
  status: completed|partial|ended_early, activeSec,
  setsDone, setsTotal, setsSkipped, reps, heldSec,
  sources: {camera, timer, manual}  // set counts
  formScore? { value, eligibleSets }, sync }

ExerciseSummary { exerciseId, unit: reps|seconds, range,
  sessions, total, bestSet { value, date, source },
  bestSession { value, date },
  formAvg? { value, eligibleSets }, points: [{date, value}] }

HistoryItem = WorkoutSummary + { dow, planned?: bool }

PersonalRecord { id, kind: max_set|most_reps_workout|
  most_exercise_workout|longest_hold|best_week|longest_streak,
  exerciseId?, unit, value, previous?, date, sessionId?,
  source, isNew (≤ 7 days) }

FormAggregate { range, exercise?, avg, eligibleSets,
  points: [{date, value, sets}], excluded: {manual, timer,
  unsupportedModel} }  // counts only, never scored

ConsistencySummary { currentStreak, longestStreak {value,
  from, to}, unit: days, rule: "calendar_day_v1",
  weeks: [{start, workouts, planned?, completed?}] }

CacheStatus { computedAt, source: local|server,
  pendingSessions, lastSyncedAt, error? }
Localization
  • English first; vi-VN from existing strings. ICU plurals for workouts, sets, reps
  • Dates and week start via Intl; "Sep 23 – Oct 8" ranges with locale range formatter
  • Durations m:ss for holds, "2 h 32" for active time; tabular figures everywhere
  • Chart labels abbreviated by locale (Wk / Tuần); allow ~35% text growth; cards wrap, numbers never truncate
Existing vs proposed
  • Existing (v1): history list + detail for push-up sessions, form score from camera push-ups, delete workout, share, AI consent
  • Phase 1–2 (proposed): tracking modes, plans, multi-exercise sessions, partial status, sync states
  • Phase 3 (proposed): everything in this file: overview, weekly/monthly analytics, records, form trends, consistency, compare
  • Assumptions (proposed): calendar-day streak rule (plan recovery/rest days count; move or skip before week end keeps a missed day); NEW badge for 7 days; 60-day offline cache; "improving fastest" rule; knee push-up scoring excluded
  • Free / Pro: not defined here. Tentative for Phase 8: longer ranges (90D / All) could be Pro; core history and records stay free
  • Never shown: calories, body metrics, injury or medical claims, combined rep+time totals
