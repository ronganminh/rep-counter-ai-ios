Guest vs signed in
  • Guest: local reminders, local events (records, recovery note) and on-device inbox. No remote push, no social / account items. Permission flow identical
  • Signed in: device token bound to userId; inbox synced across devices; preferences stored server-side
  • Sign-out: server unbinds token first, client cancels account-scoped local notifications and clears the cached inbox; plan reminders for guest data may continue only if the user keeps them
  • Account switch: notifications carry recipientUserId; mismatches show P10-12k and nothing else
Quiet-hour scheduling rules
  • Window belongs to the day it starts; cross-midnight when end < start; start = end invalid; min 30 min
  • Local reminders inside the window move to window end (once); follow-ups never stack
  • Remote push inside the window: inbox immediately, push suppressed or sent silently (no sound / banner) — server decides with the user's IANA zone
  • Security notices may bypass if "Let security notices through" is on; never uses OS time-sensitive / critical alerts
  • Time-zone change: wall-clock times follow the device; reschedule all local notifications on TIMEZONE_CHANGED / significant time change; DST gaps fire at next valid minute, overlaps once
Idempotency + offline
  • Event creation: INSERT … ON CONFLICT (recipientUserId, deduplicationKey) DO NOTHING
  • Client keeps a seen-set of notificationIds (and local ids) to drop duplicates (P10-12i)
  • Read / delete: PUT state with version; offline queue replays in order; conflicts resolve to "read" and "deleted" (monotonic)
  • Rewards: notification open never calls reward APIs; ledger is idempotent by entity id
  • Expired: expiresAt hides actions on device even offline; server rejects late actions with 410 → fallback

Notification testing checklist
  • Permission: not determined / allowed / denied / provisional / revoked while backgrounded; Android 12 vs 13+
  • Reminders: plan days only; none on recovery (Oct 21, Oct 23 sample) or after completion; move / skip; plan deleted
  • Quiet hours: same-day, cross-midnight, all days off, start = end; DST forward / back; zone change while scheduled
  • Delivery: foreground / background / terminated; cold start deep link for every route; signed-out and expired session resume
  • Privacy: generic previews by default for AI, social, billing; account switch shows P10-12k; sign-out stops push to that device
  • Inbox: read / unread counts match bell badge; offline queue; duplicates; retention
  • Safety: no repeated follow-ups; no streak threats; nothing over camera / HUD / rest timers; Voice Coach separate
  • Localization: EN / VI strings, 12 / 24-hour, long-text wrapping; VoiceOver / TalkBack names for dot, badges, toggles
