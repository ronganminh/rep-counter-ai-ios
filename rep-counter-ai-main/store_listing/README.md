# RepCoach AI — Play Store Submission Pack

This directory contains the English Google Play listing copy, policy-declaration drafts, and ready-to-upload graphics.

## Files

- `PLAY_STORE_LISTING_EN.md` — title, short description, full description, contact details, and asset order
- `DATA_SAFETY_EN.md` — suggested Data safety answers for the current MVP
- `HEALTH_APPS_DECLARATION_EN.md` — suggested Health apps declaration and safety wording
- `assets/feature-graphic-1024x500.png` — Google Play feature graphic
- `assets/app-icon-512.png` — Play Console icon, exported at exactly 512×512
- `assets/app-icon-1024.png` — high-resolution source icon (the original artwork is 1254×1254)
- `assets/screenshots/` — portrait Android screenshots captured from the current app build

Review declarations against the exact production backend configuration before submitting. Infrastructure logging, analytics, authentication, cloud sync, ads, or video uploads can change the required answers.
